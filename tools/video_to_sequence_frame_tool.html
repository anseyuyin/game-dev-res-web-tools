使用说明 · 绿幕动作视频 → 序列帧图集 编辑器

  1. 导入视频：点击「① 导入视频」或把视频拖进窗口。程序解析时长、分辨率，并按 fps 估算总帧数（可点「检测」自动估算 fps）。
  2. 定位动作：在下方时间轨点击跳转、拖动播放头预览；播放/暂停、逐帧、倍速均可。拖拽选区的左右边界（或点「设为起点/终点」）框出动作区间，再点 裁剪出片段 把后续处理限制在该区间。
  3. 框选裁剪区域：在中间预览画面里拖动矩形移动、拖 8 个把手缩放，或直接在左栏输入精确 x/y/w/h；可锁定宽高比。绿幕边缘多余区域请裁掉，导出更省内存。
  4. 调绿幕抠除：设置键色（可用「吸管」从画面取色），拖动相似度/边缘柔化/溢色抑制/透明度收缩，右侧「抠除结果」会即时刷新（防抖 100ms）。
  5. 导出帧：点「导出帧到文件夹」选择输出目录，程序逐帧抽帧→裁剪→抠像→输出带 Alpha 的 PNG（frame_0001.png…），命名模板可自定义。中途可取消。
  6. 抽帧：右侧「帧列表」中点击缩略图切换选中；或用 自动抽帧 指定保留 N 帧（首尾帧强制保留，公式 round(i·(L−1)/(N−1))）。
  7. 合成图集：设置列数/行数/间隔（默认 1px）与行/列优先顺序，点「合成图集」预览，确认后导出单张透明背景 PNG。
  8. 播放器：设置总时长或每帧时长（二者联动），播放/暂停/停止/步进，按图集坐标切割绘制，只播放选中帧。
  9. 保存 / 加载项目：保存会把 project.json 与 assets/（原始视频、帧 PNG、图集，原样保存不重编码）写入所选目录；加载时选择该目录即可完整还原编辑状态。
提示：本工具为纯前端单文件实现，处理大视频时请合理设置「缓存上限」；若浏览器不支持 File System Access API（例如 Firefox），导出与项目保存会自动降级为 ZIP/逐文件下载，加载项目降级为选择文件夹上传。
