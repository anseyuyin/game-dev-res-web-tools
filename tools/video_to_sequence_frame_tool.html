使用说明 · 绿幕动作视频 → 序列帧图集 编辑器

  1. 绑定项目目录：打开工具时先选择项目目录（空目录=新建，含 project.json=继续编辑）。之后所有编辑与资源都写入该目录；切换目录请点顶栏「📁 项目目录」，系统选择器会直接定位到当前项目目录，方便在原目录旁切换 / 新建。
  2. 导入视频：点击「① 导入视频」或把视频拖进窗口。程序解析时长、分辨率，并按 fps 估算总帧数（可点「检测」自动估算 fps）。默认会把源视频复制到项目目录 video/，重新打开项目即可直接还原。
  3. 定位动作：在下方时间轨点击跳转、拖动播放头预览；播放/暂停、逐帧、倍速均可。拖拽选区的左右边界（或点「设为起点/终点」）框出动作区间。
  4. 切片（配置，不切视频）：点时间轨工具条的 保存为切片配置（快捷键 K）把当前区间记成一条切片，可改名、改起止帧、删除；直接点击切片条目即选中并定位到该区段（时间轨处理范围会锁定为该切片并跳到起始帧），同时切换到该切片的图集。切片配置与其图集配置写入 project.json 与 clips.json，不会生成任何新视频文件。
  5. 框选裁剪区域：在中间预览画面里拖动矩形移动、拖 8 个把手缩放，或直接在左栏输入精确 x/y/w/h；可锁定宽高比。绿幕边缘多余区域请裁掉，导出更省内存。
  6. 调绿幕抠除：设置键色（可用「吸管」从画面取色），拖动相似度/边缘柔化/溢色抑制/透明度收缩，右侧「抠除结果」会即时刷新（防抖 100ms）。
  7. 导出帧 → 项目目录：设置输出子目录（默认 frames，支持占位符 {clip} 视频片段名 / {video} 源视频名 / {name} 项目名，例如 frames/{clip} → frames/attack）与命名模板（默认 frame_{clip}_{index}.png，占位符：{clip} 视频片段名＝切片名（导出全片无切片时为源视频名）· {video} 源视频名 · {index} 序列号 · {frame} 源帧号 · {time} 秒 · {name} 项目名，模板下方有实时示例），点「导出帧到项目目录」，程序逐帧抽帧→裁剪→抠像→把带 Alpha 的 PNG 直接写入项目目录；也可以「导出并打包 ZIP」下载。中途可取消。导出只写盘，完全不动右侧「帧列表」的内存数据（切片的「导出所选 / 全部切片帧」同样只写盘）；要把帧装进内存帧列表做图集拣选，请用帧列表上的「刷新帧」。
  8. 抽帧：右侧「帧列表」中点击缩略图切换选中；或用 自动抽帧 指定保留 N 帧（首尾帧强制保留）。
  9. 刷新帧（按切片）：帧列表上方的提示条里点「刷新帧」，即按当前切片区间（还没建切片时=当前处理范围）从视频重新抽帧到内存帧列表——不写项目目录、不打包，专门用来给图集拣选：抽完就能在网格里勾选帧、合成该切片图集；需要落盘时再点「写入项目目录」（会按 frames/<切片名>/ + 命名模板写出 PNG）。刷新只替换该区间内的旧帧（原帧的勾选状态会保留），其他切片的帧不受影响，刷新后按源帧号重排，图集顺序即序列顺序。
  10. 帧列表跟随切片：右侧帧列表（缩略图网格）与左侧「视频切片」一一对应——点选某条切片后，网格只显示该切片帧区间内的帧，网格上方会显示「帧列表已跟随切片 xxx · 帧 a–b · 本切片 N 帧 / 全集 M 帧」，并可一键「显示全部帧」。此时全选 / 全不选 / 反选 / 执行抽帧 / 只保留选中都只作用于当前显示范围（切片外的帧不受影响），避免误删其他切片的帧。不需要跟随可取消勾选「帧列表跟随切片」。
  11. 序列帧图集（每切片一张）：图集配置在右侧「帧列表 / 抽帧」标签页顶部。每条视频切片都有自己独立的一张图集，以切片名命名（atlas/<切片名>.png）；点图集名即可切换，点选左栏切片时也会同步切换到该切片的图集配置。合成时取该切片帧区间内的帧图（「默认 · 全部帧」= 全部帧，再按「仅选中帧」过滤）。设置列数 / 行数 / 间隔 / 行列优先后点「合成图集」；勾选「合成后自动写入项目目录」会立即落盘。切换图集时会自动恢复已合成的画面（内存缓存 / 项目目录里的 PNG）。
  12. 播放器：设置总时长或每帧时长（二者联动），播放/暂停/停止/步进，按图集坐标切割绘制，只播放选中帧。
  13. 界面状态随项目保存：左栏各组（播放 / 裁剪框 / 绿幕抠除 / 视频切片 / 导出帧 / 项目 / 快捷键）与右侧「序列帧图集」的展开 / 折叠状态会记进 project.json 的 ui.groups，下次打开该项目时原样还原（自动保存也会写入）；新建 / 重置项目时回到界面默认（仅「快捷键」默认折叠）。
  14. 保存：勾选「自动保存」后，参数、选区、切片等修改会防抖写入 project.json/clips.json；也可随时点「保存项目」或 Ctrl+S 立即保存（同时写出尚未落盘的视频、帧、图集资源）。
  15. 记住上次项目目录：绑定目录后会把它记进浏览器本地缓存（目录句柄存 IndexedDB，名称/时间存 localStorage）。下次打开工具会自动打开上次的项目，无需再选目录；若该目录已被删除或移动，程序会自动清除缓存并回到目录选择界面。若浏览器要求重新授权，欢迎页会显示「打开上次项目」按钮，点一下即可。可在左栏「项目（绑定目录）」里点「清除「上次项目目录」缓存」取消记忆。
目录结构：project.json（项目与参数 + 界面状态 ui.groups）、clips.json（切片配置 + 各切片的图集配置）、video/（源视频副本）、frames/（序列帧 PNG）、atlas/（图集 PNG，每个切片一张 <切片名>.png）。
提示：本工具为纯前端单文件实现，处理大视频时请合理设置「缓存上限」；若浏览器不支持 File System Access API（例如 Firefox），项目目录会降级为内存目录（可导出 ZIP 留存），导出与项目保存会自动降级为 ZIP/逐文件下载。
