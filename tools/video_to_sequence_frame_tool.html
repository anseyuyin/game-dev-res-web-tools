📁 第一步 · 绑定项目目录

本工具以目录为项目：所有编辑、切片配置、序列帧与图集资源都保存在该目录中。 请选择一个空目录新建项目，或选择已保存过的项目目录继续编辑。
🕘 检测到上次使用的项目目录：—
  1. 选择目录 → 自动读取其中的 project.json / clips.json；若不存在则新建项目。
  2. 导入视频（可选自动复制到 video/），在时间轨拖出区间。
  3. 「保存为切片配置」把区间记成切片（不切割视频文件），随项目持久化。
  4. 导出序列帧写入 frames/，图集写入 atlas/，全部落在项目目录里。

使用说明 · 绿幕动作视频 → 序列帧图集 编辑器

① 绑定目录→ ② 导入视频→ ③ 框选区间→ ④ 保存切片→ ⑤ 导出帧→ ⑥ 生成图集→ ⑦ 播放检查
  1. 绑定项目目录：顶栏「📁 项目目录」选空目录新建，或选已有项目继续；下次打开自动恢复上次项目。
  2. 导入视频：「① 导入视频」或把视频拖进窗口，默认复制到 video/。
  3. 框选动作区间：在时间轨拖动选区左右边界框出动作（或 [ / ] 设为起止）。
  4. 保存切片：时间轨点「保存为切片配置」（K）——切片只是帧区间，不切视频。
  5. 裁剪 + 抠像：中间预览拖裁剪框，左栏调键色 / 相似度。
  6. 导出序列帧：左栏「导出帧」设子目录与命名模板 → 点「导出帧到项目目录」。
  7. 生成图集：右侧「刷新帧」把帧抽到内存 → 「全选」勾选 → 切到「图集 / 播放」自动合成。
  8. 播放检查：图集页底部播放器：播放 / 暂停、逐帧、速度 0.1×–10×。
记住一点：i 角标＝悬停看细节，保存用 Ctrl+S。
