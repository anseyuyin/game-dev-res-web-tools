🎭 序列帧动画角色组装器

把「一张图 = 一个动画」的序列帧图在同一个坐标系里对齐原点，配好播完后的回退关系，保存成 xxx.fca.json。

工作流

  • 绑定目录：选择一个本地目录，配置存为 <工程名>.fca.json，导入的图片复制进 sprites/。
  • 导入图片：点「＋ 导入图片」或直接把图片拖进窗口；每张图自动识别行列，识别不准就手动改。
  • 切分顺序：默认列优先（从上到下取满一列再换下一列），也可切成行优先（从左到右再换行）；切分预览里的帧号、时间轴缩略图与播放取帧都按当前顺序计算。
  • 目录同步：绑定目录或加载配置后会自动扫描 sprites/，还没有动画的图片自动补建成动画（默认 12fps / 循环 / 自动识别行列）；也可点动画栏的 ⟳ 手动同步。
  • 命名：动画名严格等于图片文件名（去扩展名），界面不提供单独改名；改图片文件名请重新导入。
  • 重名图片：导入同名图片会询问「有重名图，是否覆盖」；确认后直接覆盖目录中的文件，若该图已被动画使用，则沿用该动画的行列 / 播放 / 对齐配置，只替换图片。
  • 对齐：在视口里拖 Gizmo 调位移 / 缩放，其它动画以半透明幽灵叠放作参考；Shift 吸附整数像素。
  • 状态：给非循环动画设置「结束后 → 某个动画」，死亡这类动作设为「停在末帧」。
  • 删除：删除动画会同时删除 sprites/ 里对应的图片（图片被其它动画共用时保留文件）；删除不可撤销，请确认后再点「删除」。
  • 预览：右侧预览切换动作试播，播完会按配置自动回退。
  • 保存：Ctrl+S；未绑定目录时下载 JSON，需自行把图片放到配置里的相对路径。

快捷键

空格 播放/暂停 · ←/→ 逐帧（Shift 10 帧）· Home/End 首/末帧 · W/E 位移/缩放 · F 聚焦 · 0 复位 · G 网格 · Ctrl+Z 撤销 · Delete 删除动画

说明

坐标约定：世界坐标 Y 向上、1 图素 = 1 单位、帧原点在单元格中心；配置里 transform.x/y 即该动画的原点位置。循环动画不会触发结束跳转。目录读写依赖 File System Access API，Firefox / Safari 会降级为「选文件夹 + 下载 JSON」。
