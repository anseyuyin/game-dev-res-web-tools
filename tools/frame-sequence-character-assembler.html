🎭 序列帧动画角色组装器v1.0.0

把「一张图 = 一个动画」的序列帧图对齐原点，配好播完后的回退，保存成 xxx.fca.json。

编辑器 v1.0.0 · 配置格式 v1

推荐 Chrome / Edge；Firefox / Safari 会降级为「选文件夹 + 下载 JSON」。

1 · 绑定目录图片和配置都放这里
2 · 导入 / 同步一张图 = 一个动画
3 · 对齐并保存拖 Gizmo，Ctrl+S

常用操作

  • 切分：行 / 列 / 顺序 / 帧数，识别不准就手动改。
  • 对齐：W 位移、E 等比缩放，Shift 吸附；「自动对齐」按首帧墨迹对齐到默认动画。
  • 状态：单次动作设「结束后」目标，循环动作不触发。
  • 预览：右栏切动作试播，播完按配置自动回退。
  • 工程名：同时是配置文件名，改名会在下次保存时重命名配置文件。

快捷键

空格 播放 · ←/→ 逐帧 · Home/End 首/末帧 · W/E 位移/缩放 · F 聚焦 · 0 复位 · G 网格 · Ctrl+Z 撤销 · Delete 删除

❓ 目录、导入、同步与删除
  • 目录：配置文件 <工程名>.fca.json 放根目录，图片放 sprites/。
  • URL path：地址带 ?path=D:\proj\hero（建议 URL 编码）时顶栏显示 path 徽标；首次打开会弹「需要授权工程目录」引导（显示完整路径），点「选择目录并授权」会自动复制路径并打开选择器，在底部「文件夹」栏粘贴回车即可；选一次后同一链接自动绑定，绿色徽标点击只提示、不再打开选择器。
  • 绑定：目录里只有 1 个配置会自动加载，多个会弹选择；≥2 个时顶栏出现「切换配置」。
  • 同步：绑定或加载后自动扫描 sprites/，没有动画的图片会补建（12fps / 循环 / 自动识别）；点动画栏 ⟳ 手动刷新。
  • 命名：动画名严格等于图片文件名（去扩展名），不能单独改名。
  • 重名：导入同名图片会询问是否覆盖；覆盖已被使用的图片时，沿用原动画的行列 / 播放 / 对齐，只换图。
  • 删除：确认后同时删除 sprites/ 里的图片（被其它动画共用时保留文件），不可撤销。
❓ 切分顺序与自动识别
  • 顺序：默认列优先（从上到下取满一列再换列），可切行优先；切分编号、帧轨缩略图、播放取帧都按它算。
  • 自动识别：先找透明分隔带，再用周期打分，最后按近似方格兜底；失败会回到 1×1 并提示手动填写。
  • 帧数：不超过 行×列，未使用的格子会在切分预览里标红。
❓ 对齐、Gizmo 与自动对齐
  • 坐标：世界坐标 Y 向上、1 图素 = 1 单位，帧原点在单元格中心；transform.x/y 就是该动画原点的世界位置。
  • Gizmo：W 位移（X 红 / Y 绿），E 等比缩放（中心方块）；Shift 吸附 1px / 0.05；宽高始终同比。
  • 自动对齐：取默认动画与当前动画首帧的墨迹（非透明内容）包围盒，按墨迹高度算缩放、按墨迹底边中心算位置；没有墨迹时退回帧底边中心。只改当前动画，可撤销。
❓ 状态机、播放与预览
  • 结束跳转：循环动画不会结束；非循环动画在末帧播满 1 / fps 后跳到「结束后」目标，没设目标就停在末帧。
  • 防死循环（仅预览）：记录最近 8 次自动跳转，出现 A→B→A→B 时停止跳转并提示，不改配置。
  • 预览画布：按全部动画的联合包围盒自适应，切换动作比例不跳；播完按配置自动回退。
❓ 保存、工程名与配置
  • 保存：Ctrl+S 写回配置；已有文件名时改动后 1.5s 自动保存；未绑定目录时改为下载 JSON。
  • 工程名：同时是配置文件名。输入时状态栏先显示 <新名>.fca.json（待保存），失焦 / 回车后下一次保存写入新文件并删除旧文件；目标文件名已存在时拒绝改名并还原。
  • 配置字段：rows / cols / frameCount / order / fps / loop / next / transform；version 是配置格式版本，editorVersion 是生成该文件的编辑器版本。完整格式见工具文档。
