## 1. 绿幕动作视频 → 序列帧图集

- **文件**：[`tools/video_to_sequence_frame_tool.html`](../tools/video_to_sequence_frame_tool.html)（单文件，约 2600 行，无任何外部依赖）
- **索引 id**：`green-screen-sequence-tool`
- **一句话**：把「游戏单位在绿幕前表演的动作视频」变成引擎可直接用的透明背景序列帧 / 图集，全流程在浏览器本地完成。

### 1.1 解决什么问题

美术给的动作参考通常是**绿幕拍摄或录制的视频**，而 2D 游戏需要的是**背景透明、逐帧对齐的序列帧图片**。中间的活儿（抽帧 → 裁掉多余画面 → 抠掉绿幕 → 统一尺寸 → 排成图集 → 检查动作是否流畅）过去要靠 PS 动作批处理或 AE 完成，改一个参数就要从头再跑一遍。

这个工具把整条流水线做成实时可调的：拖进视频 → 框选裁剪区域、拉几个滑块调抠像 → 立刻在右侧看到抠除结果 → 满意后一次性导出，参数不满意随时回退重来，不需要重新导素材。

### 1.2 功能一览

| 分组 | 能力 |
| --- | --- |
| **导入** | 点击导入或直接拖拽视频到窗口；解析时长 / 分辨率；`检测` 按钮用 `requestVideoFrameCallback` 采样约 1 秒自动估算 fps（匹配 23.976/24/25/29.97/30/48/50/59.94/60）；对未写入时长的 webm 做强制计算兜底 |
| **播放与定位** | 0.25x ~ 2x 倍速、逐帧步进、跳首尾帧、循环播放；当前帧号与时间码双向显示；`Home`/`End`/`←`/`→`（`Shift` 加速 10 帧）/空格 快捷键 |
| **时间轨** | Canvas 绘制的缩略图条 + 秒级标尺 + 播放头 + 选区带；点击跳转、拖动播放头、拖拽选区边界；`[` / `]` 设为起点 / 终点；`裁剪出片段` 把后续所有处理锁定在该区间 |
| **裁剪框** | 预览区拖拽移动 + 8 个把手缩放，或直接输入精确 `x/y/w/h`；可锁定 `1:1 / 16:9 / 9:16 / 4:3 / 3:4 / 2:1 / 1:2` 比例；`整幅` / `居中 512²` / `自动贴合主体` 三个快捷操作；导出时所有帧共用同一矩形 |
| **绿幕抠除** | YCbCr 色度距离键控 + alpha 渐变边缘柔化 + 溢色抑制 + 可选透明度收缩（腐蚀）；键色可用**吸管**直接从画面取色；`相似度 / 边缘柔化 / 溢色抑制 / 透明度收缩` 四个滑块，右侧预览防抖 100ms 实时刷新 |
| **导出帧** | 逐帧 `seek → 裁剪 → 抠像 → PNG（带 Alpha）`。**输出子目录**支持占位符 `{clip}` 视频片段名（导出切片时=切片名）/ `{video}` 源视频名 / `{name}` 项目名，例：`frames/{clip}` → `frames/attack`；**命名模板**可自定义（默认 `frame_{clip}_{index}.png`；占位符 `{clip}` 视频片段名＝切片名、无切片时为源视频名，另有 `{video}` 源视频名 / `{index}` 序列号 / `{frame}` 源帧号 / `{time}` 秒 / `{name}` 项目名，模板下方显示实时示例）；支持直接写入目录或打包 ZIP；**导出只写盘、完全不动右侧帧列表的内存数据**（「导出全部 / 所选切片帧」同样只写盘）；中途可取消；`缓存上限` 控制内存中保留的位图数量，超出后只留 PNG 数据、合成图集时按需重载 |
| **抽帧** | 自动抽帧保留指定总帧数 N（首尾帧强制保留，公式 `round(i·(L−1)/(N−1))`）；缩略图网格支持全选 / 全不选 / 反选 / 只保留选中；也支持导入外部 PNG 序列一起参与合成 |
| **帧列表 × 切片联动** | 帧列表（缩略图网格）跟随当前选中的**视频切片**：切到哪条切片，网格就只显示该切片帧区间内的帧（网格上方显示「切片名 · 帧区间 · 本切片 N 帧 / 全集 M 帧」，可一键「显示全部帧」）；全选 / 全不选 / 反选 / 自动抽帧 / 只保留选中都只作用于当前显示范围，切片外的帧不受影响；可取消勾选「帧列表跟随切片」改为查看全部帧 |
| **刷新帧（按切片）** | 提示条上的「刷新帧」按**当前切片区间**（无切片时=当前处理范围）从视频重新抽帧，**只进内存帧列表、不写项目目录**，专供下一步图集拣选；仅替换该区间内的旧帧并**保留其勾选状态**，其他切片的帧不动，刷新后按源帧号重排；需要落盘时再点「写入项目目录」（按输出子目录 + 命名模板写出 PNG），资源摘要会显示「内存 N 帧待写入」。职责划分：**「刷新帧」= 生成内存帧列表，「导出帧」= 只写盘** |
| **图集合成** | 设置列数 / 行数 / 间隔（默认 1px，**不缩放**，尺寸 = `cols×w+(cols−1)×gap` × `rows×h+(rows−1)×gap`）与行 / 列优先顺序；合成后可叠加网格线与帧序号辅助检查；支持缩放与适应窗口 |
| **播放器** | 按图集坐标切割绘制逐帧试播，总时长与每帧时长联动，可循环，自动跳过未选中帧 |
| **项目存档** | 保存 `project.json` + `assets/`（原始视频、帧 PNG、图集**原样保存不重编码**）到指定目录，加载时选回该目录即可完整还原编辑状态；`project.json` 带 `app` 标识与 `version` 字段，版本不一致时提示并询问是否尽力加载；左栏各组（播放 / 裁剪框 / 抠除 / 切片 / 导出 / 项目 / 快捷键）与右侧「序列帧图集」的**展开折叠状态**记在 `ui.groups` 里，随项目一起还原 |

### 1.3 典型工作流

1. **导入视频** → 点 `检测` 确认 fps 是否与拍摄一致（fps 直接决定抽帧密度）。
2. **框动作区间** → 在时间轨上拖出选区（比如 `0.8s ~ 2.4s` 的那一次挥砍），点 `裁剪出片段` 锁定。
3. **裁掉杂边** → 拖动裁剪框，或用 `自动贴合主体` 快速找主体，再手动微调；保持所有帧的裁剪矩形一致，避免动作抖动。
4. **调抠像** → 吸管取绿幕颜色，从低相似度往高调，直到绿幕消失而边缘（发丝、武器高光）不缺口；出现绿色边光时加大 `溢色抑制`。
5. **刷新帧 + 抽帧** → 点帧列表上的 `刷新帧` 把当前区间的帧生成到内存列表（`导出帧到项目目录` 只写盘、不动帧列表），再在帧列表里 `自动抽帧` 保留 N 帧，剔掉重复帧。一段视频里有多个动作时，先把每段动作 `保存为切片配置`，点选切片后帧列表只显示该区间的帧，刷新与抽帧也只在当前切片区间内生效。
6. **合成图集** → 设好列数 / 间隔 / 顺序，`合成图集` 预览，确认排布无误后 `导出图集 PNG`。
7. **试播** → 切到「播放器」标签页看动作是否连贯；不连贯就回到第 5 步调整抽帧数。
8. **保存项目** → 存到工程目录，下次改参数不用重新导视频。

### 1.5 已知限制与注意事项

- **抽帧精度**：依赖 `<video>` 的 `seek` + `seeked` 事件，对长 GOP 的 H.264 视频可能取到关键帧附近而非精确帧。追求严格帧对齐时，建议先把视频转成低压缩 / 高关键帧密度的中间格式再导入。
- **内存占用**：高分辨率 × 高帧数会吃掉大量内存。`缓存上限` 默认 240 帧，超出后自动释放位图；处理 1080p 以上素材时建议先裁剪缩小。
- **导出区间视频**是**实时录制**（`MediaRecorder` + canvas 捕获流），耗时约等于区间时长，画质取决于实时播放，仅作为可选项，不是精确转码。
- **超长视频**：所有帧都缓存在内存中，工具面向的是几秒到几十秒的动作片段，不适合整段长视频。
- **页面关闭保护**：存在未导出的帧时，关闭页面会弹出浏览器确认框。
- 首次打开会自动弹出「使用说明」弹窗，关闭后记在 `localStorage` 的 `gs_help_seen`。

## 索引页功能说明

入口：[`tools/tools_index.html`](../tools/tools_index.html)

- **搜索栏**：实时匹配工具的名称、描述、标签与文件名；支持按 `/` 聚焦、按 `Esc` 清空。
- **标签筛选**：点击标签胶囊可在标签间切换过滤，再次点击取消。
- **收藏筛选**：点击卡片右上角的 `☆` 收藏；顶部「⭐ 只看收藏」按钮可只显示已收藏的工具。
- **收藏持久化**：收藏列表保存在浏览器 `localStorage` 的 `gdrwt.favorites` 键中，清空浏览器数据会丢失。
- **空状态提示**：无匹配结果、无收藏、无工具登记时会显示对应提示。

## 如何登记一个新工具

1. 在 `tools/` 目录下创建单个 `.html` 工具文件（结构、配色与交互可参考 [`video_to_sequence_frame_tool.html`](../tools/video_to_sequence_frame_tool.html)）。
2. 打开 `tools/tools_index.html`，在 `<script>` 顶部的 `TOOLS` 数组中追加记录：

```js
{
  id:   "example-tool",       // 唯一标识，用于收藏存储，建议与文件名一致
  name: "示例工具",            // 展示名称
  desc: "一句话说明工具用途。",  // 描述，参与搜索
  file: "example-tool.html",  // 相对 tools_index.html 的路径
  icon: "🧩",                 // 一个 emoji 图标
  tags: ["示例", "工具"]       // 标签数组，参与搜索与筛选
}
```

3. 回到本文件：在「工具清单」表格补一行，并为它添加一个 `## N. 工具名` 小节（写清用途、功能、典型流程、限制）。
4. 在 [`../README.md`](../README.md) 的「现有工具」表中同步一行，并更新工具数量。
5. 提交代码。

> ⚠️ `id` 是收藏功能的存储键，工具改名时不要改 `id`，否则用户的收藏会失效。
