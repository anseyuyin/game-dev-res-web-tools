## 索引页功能说明

入口：[`tools/tools_index.html`](../tools/tools_index.html)

- **搜索栏**：实时匹配工具的名称、描述、标签与文件名；支持按 `/` 聚焦、按 `Esc` 清空。
- **标签筛选**：点击标签胶囊可在标签间切换过滤，再次点击取消。
- **收藏筛选**：点击卡片右上角的 `☆` 收藏；顶部「⭐ 只看收藏」按钮可只显示已收藏的工具。
- **收藏持久化**：收藏列表保存在浏览器 `localStorage` 的 `gdrwt.favorites` 键中，清空浏览器数据会丢失。
- **空状态提示**：无匹配结果、无收藏、无工具登记时会显示对应提示。

## 如何登记一个新工具

1. 在 `tools/` 目录下创建单个 `.html` 工具文件（结构、配色与交互可参考 [`video_to_sequence_frame_tool.html`](../tools/video_to_sequence_frame_tool.html)）。
2. 打开 `tools/tools_index.html`，在 `<script>` 顶部的 `TOOLS` 数组中追加记录：

```js
{
  id:   "example-tool",       // 唯一标识，用于收藏存储，建议与文件名一致
  name: "示例工具",            // 展示名称
  desc: "一句话说明工具用途。",  // 描述，参与搜索
  file: "example-tool.html",  // 相对 tools_index.html 的路径
  icon: "🧩",                 // 一个 emoji 图标
  tags: ["示例", "工具"]       // 标签数组，参与搜索与筛选
}
```

3. **新建该工具自己的文档** `docs/tools/<id>.md`（文件名与 `id` 一致，例：`docs/tools/example-tool.md`），内容包括：一句话简介、解决什么问题、功能一览、典型工作流、兼容性与降级、已知限制、快捷键（如有）。可复制已有文档改结构。
4. 回到本文件：在「工具清单」表格补一行，`名称` 与 `详细文档` 两列都指向第 3 步新建的文档。
5. 在 [`../README.md`](../README.md) 的「现有工具」表中同步一行，并更新工具数量。
6. 提交代码。

> ⚠️ `id` 是收藏功能的存储键，工具改名时不要改 `id`，否则用户的收藏会失效。
