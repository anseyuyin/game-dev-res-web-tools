# 🎭 序列帧动画角色组装器

> 上级索引：[工具索引](../工具索引.md) ｜ 索引 id：`frame-sequence-character-assembler`
> 工具文件：[`tools/frame-sequence-character-assembler.html`](../../tools/frame-sequence-character-assembler.html)（单文件，无任何外部依赖）
> 配置格式：`xxx.fca.json`

**一句话**：把「一张图 = 一个动画」的角色序列帧图放进同一个坐标系对齐原点（位移 + 等比缩放），配好动作播完后的回退关系，保存成引擎可直接读的 `xxx.fca.json`。

> 日常使用只看前 6 节即可；坐标约定、自动识别、状态机时序、目录与文件规则、配置字段等复杂内容都折叠在文末的 **❓ 详细说明** 里。

---

## 1. 解决什么问题

美术通常按动作分别导出序列帧（`idle.png`、`attack.png`、`death.png`…），每张图的画布大小、角色在画布里的位置、像素密度都可能不同，直接切帧播放会「跳位」；动作之间的衔接（攻击播完回 idle、死亡播完停住）也只能写死在代码里。

这个工具把「对齐」和「状态关系」做成可视化编辑：所有动画叠在同一个场景里，拖 Gizmo 调位移与缩放直到视觉重合，选好结束后回哪个动画，一键存成配置。全程本地运行，不需要引擎工程。

## 3. 典型工作流

1. **绑定目录** → 工程里的 `sprites/` 就是素材目录，已有图片会自动变成动画。
2. **导入 / 同步** → 新动作图丢进 `sprites/` 后点 ⟳，或直接拖图进来。
3. **切分** → 确认行 / 列 / 顺序 / 总帧数，识别不准就手动改，看切分预览的编号。
4. **对齐** → 选动画，按 `W` 拖 XY、按 `E` 拖中心方块等比缩放；`F` 聚焦。
5. **播放设置** → 设 fps、是否循环、是否为默认动画。
6. **状态** → 给攻击 / 死亡这类单次动作选「结束后」目标。
7. **合成预览** → 右栏切动作试播，确认原点与回退都正确。
8. **保存** → `Ctrl+S`。

## 5. 已知限制

- 只支持「一张图 = 一个动画」，不把多个动画合成一张图集。
- 帧必须紧贴排成网格；图集带描边 / 间隔时会把间隔算进帧里，需要重新导出。
- 只支持位移与**等比**缩放，没有旋转 / 剪切。
- 各动画的像素密度差异靠手动缩放对齐，不会自动估算。
- 状态机是单目标回退，不支持条件、事件、参数化过渡。
- 删除动画会真的删掉本地图片，且不可撤销。

## 7. 详细说明 ❓

<details>
<summary><b>❓ 坐标、帧原点与切分顺序是怎么约定的？</b></summary>

- **世界坐标**：Y 向上，原点在视口中心；**1 世界单位 = 1 图素**，`transform.scale = 1` 即原始像素大小。
- **帧原点**：每个帧单元的中心（`pivot = 0.5 / 0.5`），配置里预留了 `pivot` 字段，v1 不可改。
- **帧顺序**：`order` 字段，`col` = 列优先（默认，从上到下取满一列再换列），`row` = 行优先（从左到右再换行）。
- **旧配置兼容**：没有 `order` 字段时按 `row` 加载（这是加入顺序选项前的行为）。
- **命名**：动画显示名严格等于图片文件名（去扩展名），界面不提供单独改名。
- **帧数**：`frameCount ≤ rows × cols`，按顺序取前 N 帧；未使用的格子会在切分预览里标红。

```js
// 第 index 帧（0 基）对应的图集矩形
const fw = img.width / anim.cols;
const fh = img.height / anim.rows;
let col, row;
if (anim.order === "row") { col = index % anim.cols; row = (index / anim.cols) | 0; }
else                      { row = index % anim.rows; col = (index / anim.rows) | 0; }
const src = { x: col * fw, y: row * fh, w: fw, h: fh };
```
</details>

<details>
<summary><b>❓ 自动识别是怎么猜行列的？</b></summary>

1. 图片降采样到最长边 ≤ 2048，统计 alpha（无 alpha 时按背景色）投影。
2. **透明分隔带**：把行 / 列投影里连续的空白带当作网格分隔，段数即行列；先合并过窄的碎片，避免帧内特效把格数撑大。
3. **周期检测**：没有空白带时，对 2–24 格做边界打分，取「达标的最大格数」（整数倍也会达标，必须取最细一层）。
4. **近似方格兜底**：某一轴失败、另一轴可信时，按接近正方形的帧宽高推另一轴（如 6 列 × 64 宽 → 144 高按 72 推 2 行）。
5. 全部失败则回到 `1 × 1`，提示手动填写。手动改过行列后不再显示上一次识别依据。
</details>

<details>
<summary><b>❓ Gizmo、播放与状态机的精确规则</b></summary>

- **Gizmo**：屏幕固定尺寸，不随视图缩放。位移 = 红色 X / 绿色 Y 轴箭头 + 中心方块；缩放只有中心方块（斜向箭头），拖动按对角线分量算整体倍率，`scaleX === scaleY`。`Shift` 吸附 1px / 0.05。
- **原点**：世界原点十字在所有动画、包围盒与 Gizmo 之上最后绘制，不会被角色挡住。
- **播放**：`frame = floor(t × fps)`；循环取模，非循环夹到末帧；帧轨拖动时自动暂停。
- **结束触发**：非循环动画在末帧**播满一个帧时长**（`t ≥ frameCount / fps`）后触发一次 `next`；`next` 为空则停在末帧。循环动画永不触发，`next` 保留但不生效。
- **防死循环**（仅预览）：记录最近 8 次自动跳转，出现 `A→B→A→B` 时停止跳转并提示，不修改配置。
- **缩放**：全流程等比，属性面板只有一个「缩放」输入；旧配置两轴不一致时，加载取均值统一。
</details>

<details>
<summary><b>❓ 目录、导入、重名、删除与同步的规则</b></summary>

- **目录结构**：`<绑定目录>/<工程名>.fca.json` + `sprites/`；工具只写这两处。
- **绑定**：`showDirectoryPicker` 选择器会以当前 / 上次目录为 `startIn` 直接定位；目录里只有 1 个配置时自动加载，多个弹选择；已有编辑内容时不覆盖，只有 1 个配置时弹框询问是否加载。
- **切换配置**：目录里 ≥2 个 `.fca.json` 时顶栏显示「切换配置」，1 个或 0 个时隐藏。
- **目录同步**：按 `image` 路径（忽略大小写）去重，没有对应动画的图片自动补建，并标记未保存；补建结果需要保存才写入配置。
- **重名导入**：先刷新一次 `sprites/` 清单。
  - 图片已被动画使用 → 确认后写回原路径，**沿用该动画的行列 / 帧数 / fps / 循环 / next / transform**，只换图片与宽高；
  - 目录里是未配置的孤儿文件 → 确认后覆盖原文件并新建动画，不会生成 `-2`；
  - 取消 → 整张跳过。
- **删除**：确认后先 `removeEntry` 删图片，成功再移除动画；图片被其它动画共用时只删动画；删文件失败则**不删动画**并报错（否则下次同步会把图片补回来）。删除不进撤销栈，并清空撤销历史。
- **复制路径 / 打开资源管理器**：浏览器不暴露绝对路径，也无法拉起资源管理器，因此不提供。
</details>

<details>
<summary><b>❓ <code>.fca.json</code> 完整字段与引擎读取示例</b></summary>

> 更完整的格式规范（字段语义、容错、JSON Schema、参考实现）见 [`docs/formats/fca-json.md`](../formats/fca-json.md)。

```json
{
  "app": "frame-sequence-character-assembler",
  "version": 1,
  "name": "hero",
  "savedAt": "2026-11-09T08:30:00.000Z",
  "defaultAnimation": "idle",
  "assets": [
    { "path": "sprites/idle.png", "width": 512, "height": 512, "bytes": 48213 }
  ],
  "animations": [
    {
      "id": "idle",
      "name": "idle",
      "image": "sprites/idle.png",
      "rows": 4,
      "cols": 8,
      "frameCount": 32,
      "order": "col",
      "fps": 12,
      "loop": true,
      "next": null,
      "pivot": { "x": 0.5, "y": 0.5 },
      "transform": { "x": 0, "y": 0, "scaleX": 1, "scaleY": 1 }
    }
  ],
  "editor": { "zoom": 1, "panX": 0, "panY": 0, "showGrid": true, "ghostMode": "first-frame" }
}
```

| 字段 | 说明 |
| --- | --- |
| `app` / `version` | 固定标识与格式版本（当前 `1`）；版本不同会提示并尽力加载 |
| `name` | 工程名 |
| `defaultAnimation` | 默认动画 id，启动 / 停止时播放 |
| `assets[]` | 图片清单（路径、宽高、字节数），加载时用于校验，不一致只提示 |
| `animations[].id` | 唯一稳定标识，引擎引用它 |
| `animations[].name` | 恒等于图片文件名（去扩展名），加载时按 `image` 校正 |
| `animations[].image` | 相对绑定目录的图片路径 |
| `animations[].rows / cols` | 网格行列，均 ≥ 1 |
| `animations[].frameCount` | 1 ~ rows×cols，取前 N 帧 |
| `animations[].order` | `col` 列优先（默认）/ `row` 行优先；缺省按 `row` 兼容旧配置 |
| `animations[].fps` | 1 ~ 120 |
| `animations[].loop` | 循环；为 `true` 时 `next` 不生效 |
| `animations[].next` | 播完跳到哪个动画 id；`null` = 停在末帧 |
| `animations[].pivot` | 帧原点归一化坐标，v1 固定 `0.5 / 0.5` |
| `animations[].transform` | 世界像素位移（Y 向上）与**等比**倍率（`scaleX === scaleY`） |
| `editor` | 视图状态，仅本工具使用，引擎可忽略 |

```js
// 帧矩形
const fw = img.width / anim.cols, fh = img.height / anim.rows;
let col, row;
if (anim.order === "row") { col = index % anim.cols; row = (index / anim.cols) | 0; }
else                      { row = index % anim.rows; col = (index / anim.rows) | 0; }

// 帧中心的世界坐标 = (transform.x, transform.y)；canvas 左上角（Y 向下）：
const dw = fw * transform.scaleX, dh = fh * transform.scaleY;
const dx = transform.x - dw * 0.5;
const dy = originScreenY - transform.y - dh * 0.5;

// 每帧时长 = 1 / fps；loop=false 时末帧播满 1/fps 后执行 next
```

<details>
<summary><b>❓ 性能、撤销与降级实现说明</b></summary>

- **渲染**：不生成中间图，切帧直接用 `drawImage(img, sx, sy, sw, sh, ...)`；切分预览与帧轨只在需要时重绘。
- **幽灵**：非选中动画以 0.28 透明度叠放，可关闭；「全部播放」时共用同一时钟。
- **撤销**：覆盖切分参数、fps、顺序、循环、默认动画、结束跳转、位移 / 缩放；**新增 / 删除动画不进撤销栈**（删除还会清空历史）。数值输入框在第一次按键时记撤销点。
- **自动保存**：已绑定目录且已有文件名时，改动后 1.5s 防抖写盘；无独立开关。
- **降级**：无 `showDirectoryPicker` 时，「绑定目录」改为 `<input webkitdirectory>`，资源进内存，保存只下载 JSON；图片需用户自行放到配置里的相对路径。
- **验证**：Chrome 下用 Playwright 覆盖了导入、自动识别、Gizmo、播放、状态机、预览、撤销、保存 / 加载、目录同步、重名覆盖、删除等流程；原生目录选择器需手动授权验证。
</details>
