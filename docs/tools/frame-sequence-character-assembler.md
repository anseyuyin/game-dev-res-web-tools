# 🎭 序列帧动画角色组装器

> 上级索引：[工具索引](../工具索引.md) ｜ 索引 id：`frame-sequence-character-assembler`
> 工具文件：[`tools/frame-sequence-character-assembler.html`](../../tools/frame-sequence-character-assembler.html)（单文件，约 3000 行，无任何外部依赖）
> 配置格式：`xxx.fca.json`（frame-sequence character assembler）｜ 格式规范：[fca-json.md](../formats/fca-json.md)
> 状态：**已实现 v1.0**（2026-11-09）——单文件工具已落地，与设计草案的差异见 §15

**一句话**：把一组「一张图 = 一个动画」的角色序列帧图，放进同一个坐标系里对齐原点（位移 + 缩放），配好动作播完后的回退关系，保存成引擎可直接读的 `xxx.fca.json`。

---

## 1. 解决什么问题

2D 角色的动作通常由美术按动作分别导出序列帧图（`idle.png`、`attack.png`、`death.png`…），每张图内部按行列切帧。问题在于：

- 每个动作导出时的**画布大小、角色在画布里的位置、像素密度都可能不同**，直接切帧播放会「跳位」——idle 站着的位置和 attack 挥砍的位置差几十像素，缩放也不一致。
- 动作之间还需要**衔接关系**：攻击播完要回 idle，死亡播完要停住。这套关系目前只能由程序在代码里硬编码。

这个工具把「对齐」和「状态关系」两件事变成可视化编辑：把所有动画叠在同一个场景里，拖 Gizmo 调每个动画的位移与缩放直到视觉重合，选好「播完 → 回哪个动画」，最后一键存成配置。全程本地运行，不需要引擎工程。

## 2. 关键约定（先定死，避免实现反复）

| 项 | 约定 | 理由 |
| --- | --- | --- |
| 坐标系 | **世界坐标 Y 向上**，原点在视口中心；canvas 渲染时做一次翻转 | 与游戏引擎 / Spine 一致，导出配置不需要二次换向 |
| 单位 | **1 世界单位 = 1 图素**（图片原始像素），不做 DPI 缩放 | 美术按同一像素密度导出时，scale = 1 即为正确大小 |
| 帧原点 | 每个帧单元的**中心**（`pivot = 0.5 / 0.5`）；字段先写入，v1 固定不可改 | 大多数序列帧导出会把角色居中；预留 pivot 便于后续扩展 |
| 帧顺序 | **默认列优先**（`order: "col"`）：从上到下取满一列，再换下一列；可切换行优先（`"row"`，从左到右、再换行）。切分预览的帧号按当前顺序编号 | 按美术导出习惯选择；旧配置没有 `order` 字段时按行优先加载，保持原行为 |
| 帧切分 | 单元格宽高 = `W / cols`、`H / rows`，允许小数，不强制整除（不整除时提示） | 避免因 1px 余数导致整张图错位 |
| 帧数 | `frameCount ≤ rows × cols`，取前 N 帧（最后一行可以不满） | 兼容「最后一行没铺满」的导出图 |
| 循环 | `loop = true` 的动画永不结束，`next` 不生效（UI 置灰） | 语义唯一，避免歧义 |
| 结束回退 | 非循环动画**完整播放到末帧并停留满一帧时长**后触发一次 `next`；`next = null` 表示停在末帧 | 「死亡」这类动作需要停在末帧而不是消失 |
| 默认动画 | 全局唯一，`defaultAnimation` 指向某个动画 id；启动 / 停止时播放它 | 合成预览与引擎初始化都需要一个入口动作 |
| 动画 id / 名称 | **严格保持「图片名 = 动画名」**：显示名固定为图片文件名（去扩展名），不可编辑；`id` 由文件名派生并保证唯一（重名加 `-2`）。配置里的 `name` 只是冗余记录，加载与保存时都会按 `image` 重新校正 | 避免「文件名 / 动画名」两套名字不同步；改名只能改图片文件名 |

## 4. 功能设计

### 4.1 工程目录与绑定

- 入口：顶栏 `📁 绑定目录`，用 `showDirectoryPicker()` 选一个本地目录；目录职责：

```
<绑定目录>/
├─ hero.fca.json        # 编辑状态（本工具唯一产物）
├─ sprites/             # 导入时复制进来的序列帧图
│  ├─ idle.png
│  └─ attack.png
└─ （目录里已有的其它文件不读、不改、不删）
```

- 绑定后：目录句柄存 IndexedDB，下次打开可「恢复该目录」（浏览器仍会要求一次授权）。
- 目录内若已有 `.fca.json`：1 个则自动加载，多个弹选择；没有则提示「新建工程」（不立刻写文件，首次保存才创建）。
- 顶栏「切换配置」按钮只在目录里有 **≥2 个** `.fca.json` 时出现（1 个或 0 个时隐藏）；会话里已有内容又绑定到只有 1 个配置的目录时，会弹确认框询问是否加载该配置，避免按钮隐藏后无法切换。
- 工具只写 `.fca.json` 与 `sprites/` 下的图片；**唯一的删除操作是「删除动画」**——确认后会连同 `sprites/` 里的对应图片一起删除（图片被其它动画共用时只删配置、保留文件），不可恢复。
- **目录即清单**：`sprites/` 里每张图片都应该有对应动画。绑定目录、加载配置后会自动扫描一遍，把还没有配置的图片自动补建成动画（默认 12fps / 循环 / 自动识别行列）；也可点动画栏的 **⟳** 手动同步（用于在工具外往目录里放图后刷新）。
- 未绑定目录时仍可导入图片、编辑（内存态），但顶栏持续提示「未绑定目录 · 修改不会落盘」。

### 4.2 导入序列帧图

两种入口，等价：

| 入口 | 行为 |
| --- | --- |
| 点击 `＋ 导入图片` | `<input type="file" multiple accept="image/png,image/jpeg,image/webp">` |
| 拖拽 | 拖到左栏动画列表或视口均可；一次拖多张 = 一次导入多个动画；拖入文件夹时递归筛选图片（`webkitGetAsEntry`，可选增强） |

单张图片的处理流程：

1. 校验类型与尺寸（`<img>` 解码失败 / 0 字节 → 明确中文报错，不建条目）。
2. 求 `id`：文件名去扩展名（`attack_01.png` → `attack_01`），非法字符替换为 `-`，重名追加 `-2`、`-3`。
3. 绑定目录时把文件写入 `sprites/<basename>`。若目录中已有同名图片，**弹提示框「有重名图，是否覆盖？」**：
   - `覆盖`：直接写回该路径（不再生成 `-2`）。若该图已被某个动画使用，则**沿用该动画的行列 / 帧数 / fps / 循环 / 结束跳转 / 对齐配置**，只替换图片与尺寸；若是目录里的孤儿文件，则覆盖后按新图新建动画。
   - `取消`：跳过该文件，目录与动画都不变。
4. 建动画条目，**自动跑一次「自动识别」**（见 4.3）回填行列，用户可立即手改。
5. 新动画默认值：`fps = 12`、`loop = true`、`next = null`、`transform = {x:0, y:0, scaleX:1, scaleY:1}`；若当前没有默认动画，则把这张设为默认。
6. 选中新动画并允许立即播放。

### 4.3 切分参数与自动识别

属性面板字段（改动即时生效、即时预览）：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| 每行帧数 `rows` | 整数 ≥ 1 | 行数 |
| 每列帧数 `cols` | 整数 ≥ 1 | 列数 |
| 总帧数 `frameCount` | 整数 1 ~ rows×cols | 默认 = rows×cols；小于上限表示末行/末列不用，未用格子按当前顺序标红 |
| 行/列顺序 `order` | `列优先 ↓→`（默认）/ `行优先 →↓` | 决定帧号在图上的走法；切分预览、时间轴缩略图、播放取帧统一按它计算 |
| 播放速度 `fps` | 1 ~ 120 | 每秒帧数；支持 0.5 步进 |
| 循环 `loop` | 布尔 | 循环时 `next` 置灰 |
| 默认动画 | 单选 | 全列表唯一 |
| 结束后跳转 `next` | 下拉：`无（停在末帧）` / 其它动画 | 见 4.6 |

辅助显示：`图 512×512 · 帧 128×128 · 32 帧 · 时长 2.67s`，不整除时显示黄色提示。

**「自动识别」按钮**（可重复点击，只回填不自动保存）：

1. 把图片降采样到最长边 ≤ 2048 后读 `ImageData`（识别用降采样图，切分始终用原图）。
2. **优先走透明分隔带检测**（序列帧绝大多数带 alpha）：
   - 列投影 `colInk[x] = 该列 alpha > 16 的像素数`，把连续 `colInk == 0` 的区间视为竖向空白带；宽度 ≥ `minGap`（默认 1px）的空白带把图切成若干内容段 → 段数即 `cols`。
   - 行方向同理得 `rows`。
   - 校验各段宽高方差 ≤ 10% → 高置信；否则降为中置信并在按钮旁标注。
3. **无 alpha 或找不到空白带时**走周期检测：
   - 枚举常见帧尺寸候选（32 / 48 / 64 / 96 / 128 / 192 / 256，宽高独立），要求 `W % fw == 0`、`H % fh == 0`；
   - 对每个候选计算「相邻单元格边界列/行像素差」作为周期吻合度，取分数最高者；
   - 分数都低于阈值 → 回退 `1×1`，提示「未识别到网格，请手动填写行列」。
4. 结果回填 `rows / cols / frameCount`，并在属性面板显示识别依据（透明分隔 / 周期 / 手动）。
5. 用户手动改过行列后，仅点按钮才重新识别，不自动覆盖。
6. 属性面板底部给一张**切分预览**（高 196px）：缩略图 + 网格线 + 帧序号（格子够大时显示序号），未使用的格子用红色标出。预览支持**滚轮以光标为锚点缩放**（40%–1600%）、**按住左键拖拽平移**、**双击复位**，右下角显示当前缩放比例与操作提示。

### 4.4 编辑视口与 Gizmo

**视口内容**（自下而上绘制）：

1. 背景（棋盘 / 深灰 / 浅灰，可切换；棋盘用于检查透明边缘）。
2. 世界网格（`G`，默认 32px，缩放到一定程度以下自动隐藏）。
3. **幽灵动画**：列表中除选中动画外的所有动画，以各自 transform 绘制在当前帧，透明度 0.28，可用工具条 👻 一键关闭。默认停在**首帧**；打开「全部播放」开关后各动画按各自时钟播放（用于检查多个动作是否协调）。
4. 选中动画：不透明绘制，最后绘制（永远置顶）。
5. 叠加层：原点十字（世界 `(0,0)` 常显）+ 脚底线（`y = 0`）+ 选中动画的 pivot 点与包围盒。

**视图操作**：滚轮以光标为锚点缩放（2% ~ 800%）；中键或右键拖拽平移；`F` 聚焦选中动画包围盒；`0` 复位（100% + 居中）；工具条 `▧` 循环切换棋盘 / 深灰 / 浅灰背景。

**Gizmo**（参考 `spine-previewer.html` 的 Unity 风格，屏幕固定尺寸、不随视图缩放）：

| 工具 | 手柄 | 拖动效果 |
| --- | --- | --- |
| 位移（`W`，默认） | 红色 X 轴箭头、绿色 Y 轴箭头、中心方块 | 轴箭头 = 单轴位移；中心方块 = XY 自由拖动 |
| 缩放（`E`） | 只有中心方块（带左右两条斜向箭头） | **等比缩放**，宽高同步变化，不提供分轴手柄 |

- 位移轴按世界轴（Y 向上）；缩放只有一个整体倍率，`scaleX` 与 `scaleY` 恒等。
- 吸附：按住 `Shift` 时位移吸附 1px、缩放吸附 0.05；中心方块拖过原点附近 4px 时吸附到整数。
- 拖动时实时更新属性面板数值；输入框失焦后规范化为两位小数。
- 属性面板同时提供数值输入：`X`、`Y`、`缩放` + `重置` 按钮（无分轴输入、无等比锁开关）。
- 支持 `Ctrl+Z` / `Ctrl+Shift+Z` 撤销重做（粒度 = 一次拖动 / 一次输入提交），至少覆盖 transform 与切分参数。

### 4.5 底部播放条与帧轨

- 控件：`⏮` 首帧 / `⏪` 上一帧 / `▶⏸` 播放暂停 / `⏩` 下一帧 / `⏭` 末帧；`fps` 输入；`循环` 开关（写回该动画配置）；速度倍率（仅预览用，不写入配置，0.25x ~ 2x）。
- 指示：`当前帧号 / 总帧数`、`时间 / 总时长`。
- **帧轨**：Canvas 绘制的缩略图条（每帧一张 `createImageBitmap(img, sx, sy, fw, fh)` 缩略图，缓存到该动画），叠播放头；点击跳帧、拖动 scrub（拖动时自动暂停）、帧多时横向滚动。
- 播放逻辑：`rAF` + 时间累加，`frame = floor(t * fps)`；循环取模，非循环 `clamp` 到末帧并触发一次结束事件（驱动 4.6 与右栏预览）。
- 切换选中动画时重置播放头到该动画当前时间（默认 0），保留面板滚动位置。

### 4.6 动画状态（播完后回退）

- 每个动画一个 `next` 字段，属性面板里是下拉：`无（停在末帧）` + 其它所有动画。
- 编辑器内的语义（与引擎侧一致，必须写进文档与配置）：

```
非循环动画：t 从 0 开始，last = (frameCount - 1) / fps
           idx = min(floor(t * fps), frameCount - 1)
           当 t >= frameCount / fps（末帧已完整显示一帧时长）→ 触发一次 end
           end 时：next 存在 → 切到 next 的第 0 帧并继续播放
                   next 为空 → 停在末帧，不再触发
循环动画：idx = floor(t * fps) % frameCount，永不触发 end，next 字段保留但不生效
```

- **防死循环**（仅影响预览，不改配置）：同一次自动跳转后至少播放 1 帧才允许再次触发；记录最近 8 次跳转，出现 `A→B→A→B` 这类 2 周期重复时停止自动跳转并在预览区提示「检测到状态循环」。
- 列表行内直接显示结果：`attack → idle`、`death → 停在末帧`；`next` 指向的动画被删除/改名时，加载与删除时都做校验，断链降级为「停在末帧」并标黄。
- 可选增强（不进 v1）：在右栏画一张小的有向图（节点=动画，边=next），一眼看出状态闭环。

### 4.7 合成预览（右栏）

- 独立 canvas，与编辑视口**共用同一套绘制函数**（`drawAnimation(ctx, anim, frame, transform)`），保证「编辑器里怎么对齐，预览里就怎么播」。
- 动作按钮：每个动画一个 chip（默认动画带 ⭐），点击立即从第 0 帧播放；非循环动画播完按 `next` 自动切换，循环动画持续循环。
- 控件：`重播`（当前动作回到第 0 帧）、`停止`（回到默认动画第 0 帧并暂停）、背景切换（棋盘 / 深灰 / 浅灰）、`原点` 开关（叠加世界原点十字）。画布永远按全部动画的联合包围盒自适应，保证切换动作时比例不跳变。
- 状态行：`当前动画 · 帧号 · 循环/单次 · 结束→xxx`；跳转发生时短暂高亮。
- 可选：`截图` 按钮把当前预览帧导出 PNG（`canvas.toBlob` + 下载），方便发群确认。

### 4.8 保存 / 加载 / 撤销

- `Ctrl+S`：写回绑定的 `<name>.fca.json`；未绑定目录时弹出「另存为」下载 JSON。
- 脏标记：任何改动 → 顶栏 `● 未保存`；保存成功 → `● 已保存（时间）`。
- 自动保存：**已绑定目录且已有文件名**时，改动后 1.5s 防抖写入；写失败只提示不阻塞编辑（无独立开关，首次保存前不会自动新建配置）。
- 未保存时关闭页签 → `beforeunload` 确认。
- 加载：读取 `.fca.json` → 校验 `app` / `version` → 按 `animations[].image` 从目录读取图片 → 逐项校验（缺图、尺寸与 `assets` 记录不符、行列非法、`next` 断链）→ 汇总成一份问题清单，允许「忽略并继续」。
- 版本策略：`version` 与程序不一致时提示并按当前版本尽力加载；未来字段新增只做向后兼容（旧程序读新配置时忽略未知字段）。

| `assets[].width/height/bytes` | number | ✅ | 与磁盘文件核对，不符时标黄提示 |

| `animations[].order` | `"col"` \| `"row"` | ✅ | 帧序号走法：`col` 列优先（默认）、`row` 行优先；缺省按 `row` 兼容旧配置 |
| `animations[].fps` | number | ✅ | 1 ~ 120 |
| `animations[].loop` | boolean | ✅ | 循环 |
| `animations[].next` | string \| null | ✅ | 结束跳转目标；`loop = true` 时无效 |
| `animations[].pivot` | object | ✅ | 帧原点归一化坐标，v1 固定 `0.5 / 0.5`，仅写入不编辑 |
| `animations[].transform` | object | ✅ | `x / y` 世界像素位移（Y 向上）；`scaleX / scaleY` 为**等比**倍率，两值始终相等（保留双字段以兼容引擎侧读取） |
| `editor` | object | ❌ | 视图状态，仅本工具使用，引擎可忽略 |

### 引擎侧读取约定

```js
const fw = img.width / anim.cols;
const fh = img.height / anim.rows;
let col, row;
if (anim.order === "row") {                   // 行优先：从左到右，再换行
  col = index % anim.cols;
  row = (index / anim.cols) | 0;
} else {                                      // 列优先（默认）：从上到下，再换列
  row = index % anim.rows;
  col = (index / anim.rows) | 0;
}
const src = { x: col * fw, y: row * fh, w: fw, h: fh };

// 世界坐标 Y 向上、帧原点在单元格中心：
//   帧中心的世界坐标 = (transform.x, transform.y)
//   canvas 左上角（Y 向下）：
const dw = fw * transform.scaleX, dh = fh * transform.scaleY;
const dx = transform.x - dw * 0.5;
const dy = originScreenY - transform.y - dh * 0.5; // originScreenY = 世界原点在画布上的 y

// 每帧时长 = 1 / anim.fps；loop=false 时末帧播满 1/fps 后执行 next
```

## 7. 边界与错误处理

| 情况 | 处理 |
| --- | --- |
| 图片无法解码 / 不是图片 | 该文件跳过，汇总提示「N 个文件导入失败」，其余继续 |
| 行列乘积 < frameCount | 自动把 frameCount 夹到上限并提示 |
| 图宽高不能被行列整除 | 允许，显示「帧尺寸 127.5×128（非整数）」黄色提示 |
| 图片尺寸过大（> 8192） | 允许导入但提示内存风险，帧轨缩略图降采样 |
| 同名图片导入 | 弹「有重名图，是否覆盖？」；确认后写回原路径，已配置的动画保留行列 / 播放 / 对齐配置，只换图；取消则跳过。目录里同名但未配置的孤儿文件也会被识别 |
| `next` 指向已删除的动画 | 降级为 `null`，标黄提示 |
| 循环动画配了 `next` | UI 置灰，配置保留（切回单次即恢复） |
| 默认动画被删除 | 自动指向列表第一个动画 |
| 删除动画 | 二次确认后删除配置项，并删除 `sprites/` 下的对应图片；图片被其它动画共用或未绑定目录时只删配置项；本地图片删除失败则**不删除动画**并提示（避免下次扫描图片又被补回来） |
| 未绑定目录就保存 | 下载 `.fca.json`，并提示「图片需自行放到配置里的相对路径」 |
| 目录写入被拒（权限过期） | 提示重新授权，编辑不中断 |
| 加载时缺图 | 列表项标红，视口用占位框显示尺寸，允许重新指定文件 |
| 状态跳转成环 | 预览限流 + 提示，不修改配置 |

## 8. 性能与实现要点

- **不生成中间图**：切帧一律用 `drawImage(img, sx, sy, sw, sh, dx, dy, dw, dh)`；原图解码为 `HTMLImageElement` / `ImageBitmap` 各缓存一份。
- **帧轨缩略图**：不缓存中间图，每帧直接用 `drawImage(img, sx, sy, sw, sh, ...)` 画进帧轨画布；只在帧号 / 动画 / 画布尺寸变化时重绘，播放时开销仅限一次 `drawImage`。
- **识别算法**：降采样到 ≤ 2048 后再扫描投影，O(W×H) 一次；大图不阻塞（必要时 `requestAnimationFrame` 分块）。
- **幽灵渲染**：默认只画各动画首帧，且限制在视口可视区内；「全部播放」时若动画数 > 12 提示降级。
- **播放**：单一 `rAF` 循环驱动「编辑器 + 右栏预览」，各自维护时间；页面隐藏（`visibilitychange`）时暂停。
- **状态**：单一 `state` 对象 + `render()`，不引入框架；事件用委托，避免每次重建 DOM。

## 10. 已知限制（设计阶段已知）

- 只支持「一张图 = 一个动画」，不支持一张图里多段动画、也不支持把多个动画合成一张图集。
- 不支持旋转 / 剪切；序列帧对齐通常只需要位移与缩放。
- 帧切分假定**无间隔紧贴**网格；若美术导出的图带描边或间隔，`W/cols` 会把间隔算进帧里，表现为边缘留白，需要重新导出或用外部工具补边。
- 各动画的像素密度差异靠手动 scale 对齐，没有自动估算。
- 不做资源压缩 / 转码，导入的图片按原样复制。
- 回退关系是**单目标状态机**，不支持条件跳转、事件、参数化过渡。

## 13. 待确认问题

以下按推荐方案定稿，若与引擎侧约定不一致再调整：

1. **Y 轴方向**：配置里 `transform.y` 向上为正（游戏惯例）。若引擎侧希望直接用屏幕坐标（Y 向下），导出时加一个 `"yAxis": "up" | "down"` 字段并在 UI 里切换。
2. **图片归属**：导入时**复制**进 `sprites/`（推荐，工程自包含）；若希望只引用外部路径，需要允许配置里出现 `../` 相对路径。
3. **pivot**：v1 固定帧单元中心；若美术导出是「底边对齐」，可以改用 `pivot.y = 0`，但需要逐个动画确认。
4. **是否需要导出合成图集**（把对齐后的各动画烘成一张图 + 每动画帧区间）——v1 不做，若引擎侧需要可作为 M5。

## 15. 实现说明（v1.0）

与设计草案相比，落地版本的具体取舍：

| 项 | 实现 |
| --- | --- |
| 自动识别 | 降采样到 ≤ 2048 后统计 alpha / 背景色投影。优先用**透明分隔带**（先把间隔过小的碎片段合并，避免帧内特效、文字把格数撑大）；分隔带不成立时对 2–24 格做**边界打分，取达标的最大格数**（真实格数的整数倍也会达标，必须取最细一层）；某一轴完全失败且另一轴可信时，用**近似方格**兜底（如 6 列 × 64 宽 → 144 高按 72 推 2 行）。 |
| 幽灵叠放 | 非选中动画 alpha 0.28，选中动画最后绘制；工具条可关幽灵、可让所有动画同时播放。 |
| 帧轨 | 直接 `drawImage` 绘制，无中间位图缓存；帧数多时自动压缩格子宽度，仍保留点击 / 拖动定位。 |
| 撤销 | 覆盖切分参数、fps、循环、默认动画、结束后跳转、位移 / 缩放；**新增 / 删除动画不进撤销栈**（删除前有二次确认）。数值输入框在第一次按键时记撤销点，避免每敲一个字符压一条。 |
| 保存 | 顶栏「保存」= 写回 `<工程名>.fca.json`；未绑定目录 / 降级模式改为浏览器下载。顶栏不再提供独立的「下载 JSON」按钮（`Ctrl+S` 的行为不变）。自动保存仅在**已绑定目录且已有文件名**时启用（改动后 1.5s 防抖）。 |
| 加载 | 绑定目录后：无动画时自动打开唯一的配置，多个配置弹选择；当前已有编辑内容时不覆盖。目录里只有 1 个配置时按钮隐藏，改由绑定后的确认框询问是否加载；≥2 个时顶栏显示「切换配置」。缺图 / 尺寸不符 / `next` 断链会汇总成一条警告，不阻断编辑。 |
| 降级 | 无 `showDirectoryPicker` 时，「绑定目录」改为 `<input webkitdirectory>` 选文件夹，资源进入内存目录，保存只下载 JSON。 |
| 切分预览交互 | 画布高 196px；滚轮以光标为锚点缩放（40%–1600%）、左键拖拽平移、双击复位；缩放状态按动画各自保存（只存在于内存）。 |
| 目录同步 | 绑定目录 / 加载配置后扫描 `sprites/`（动画按 `image` 路径去重），没有配置的图片自动补建成动画并标脏；动画列表头的 **⟳** 可手动重新扫描（工具外新增图片时用）。补建是内存行为，需要保存才写入 `.fca.json`。 |
| 重名覆盖 | 导入前先强制刷新一次 `sprites/` 清单。命中「已有动画使用该图」时保留原动画的切分 / 播放 / 结束跳转 / 对齐，只换图片和宽高；命中「目录里有孤儿文件」时覆盖原文件并新建动画，不生成 `-2`。取消则整张跳过。 |
| 行列顺序 | 新增 `order` 字段：新导入 / 目录补建的动画默认 `col`（列优先）；切分预览按当前顺序重新编号并标红未用格子；旧配置缺 `order` 时按 `row`（行优先）加载，保证已发布工程播放顺序不变。 |
| 删除动画 | 确认框会写明「会同时删除本地图片 `sprites/xxx.png`」；确认后先 `removeEntry` 删文件，成功再移除动画。图片被其它动画共用时只移除动画；本地删除失败则保留动画并报错。删除不进撤销栈，并清空撤销 / 重做历史（避免撤销回缺图片的旧状态）。 |
| 命名规则 | 显示名一律取 `image` 最后一段去扩展名：导入、目录补建、重名覆盖、复制迁移、加载、保存、撤销都按 `image` 校正，不再生成「name (2)」这类与文件无关的名字；`id` 仍可加 `-2` 保证唯一。 |
| 切换配置按钮 | 文案由「打开配置」改为「切换配置」；缓存目录内 `.fca.json` 数量，**≤1 时隐藏**，≥2 时显示并以 tooltip 标注数量。绑定目录、保存成功后、载入降级文件夹、点按钮时刷新计数。 |
| 原点层级 | 世界原点十字在**所有动画、包围盒、Gizmo 之上最后绘制**，不会被选中动画挡住。 |
| 等比缩放 | Gizmo 缩放只保留中心方块（斜向箭头提示），拖动按对角线分量计算整体倍率；属性面板只有一个「缩放」输入；`scaleX` / `scaleY` 恒等。旧配置若两轴不一致，加载时取均值统一。 |
| 额外功能 | 像素风最近邻开关（▣）、「全部播放」、预览背景三种、预览原点、`pivot` 字段预留、`editor` 视图状态随配置保存。 |
| 未实现 | 预览截图导出、状态机有向图、pivot 编辑、旋转、合成图集烘焙（均保留在 §14）。 |

**已验证**（Chrome，Playwright 自动化 + 内存目录模拟）：

- 三张测试图（256×128 / 4 列 2 行、384×144 / 6 列 2 行、256×128 / 4 列 2 行）自动识别全部正确。
- 拖 Gizmo：40px 屏幕位移在 613% 缩放下得到 `x = 6.52`；缩放拖动 32px 得到 `scaleY = 1.2`，数值面板实时同步。
- 状态机：`attack` 关闭循环、结束 → `idle`，预览播完自动切到 `idle`；`death` 无结束目标时停在末帧并停止。
- 撤销 / 重做、帧轨点击跳帧、帮助弹窗、保存 / 下载回退、目录写入（内存句柄模拟）、图片迁移到 `sprites/`、清空会话后重新加载配置均通过。
- 目录同步：`sprites/` 下放 a/b 两张图，`syncSpritesFromDir` 自动补建 2 个动画并识别出 2×2；手动点 ⟳ 能把后加的 c.png 补成第 4 个动画。

- 行列顺序：默认 `col` 时 `frameRect(a, 1)` 取到左列第 2 格（`sx=0`）；切到 `row` 后同一帧号取到第一行第 2 格（`sx=帧宽`）；保存的配置带 `order`，旧配置缺字段时按 `row` 加载。
